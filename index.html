How to use Pencil

  • Drag to draw a line
  • Click to start a note
  • Right-click to delete either
  • ⌘Z / Ctrl+Z to undo
  • ⌘F / Ctrl+F to search notes
  • Hold Option/Alt to select PDF text
  • ⌘⇧F / Ctrl+Shift+F to search PDF text
